# SQL Business Sales Analysis

## Project Overview
This project uses SQL to analyze sample sales data and understand business performance across products and regions.

## Objectives
- Calculate total revenue, profit, and quantity sold.
- Identify the best-performing products.
- Compare sales performance across regions.
- Analyze product-wise profit.
- Find orders with sales above the average.
- Rank products based on revenue.

## Dataset
The dataset contains 10 sample sales records.

Columns include:
- `order_id` — Unique order number
- `product` — Product name
- `category` — Product category
- `region` — Sales region
- `sales_amount` — Revenue from the order
- `profit` — Profit earned
- `quantity` — Units sold

## Tools Used
- SQL
- GitHub

## Key Findings
- Total Revenue: 397,000
- Total Profit: 60,000
- Total Quantity Sold: 72 units
- Top Product by Revenue: Laptop — 210,000
- Highest-Selling Region: South — 112,000

## SQL Skills Demonstrated
- SELECT and WHERE
- GROUP BY and ORDER BY
- SUM() and AVG()
- Subqueries
- RANK() window function

## Conclusion
This project demonstrates how SQL can be used to summarize sales data, compare business performance, and identify useful insights for business decision-making.

*Note: This project uses sample data for learning and demonstration purposes.*
